💖 Will You Be My Valentine?
Este é um projeto interativo e divertido desenvolvido como uma surpresa romântica. A aplicação utiliza uma lógica lúdica onde o botão "No" (Não) foge do cursor ou muda de posição, tornando a resposta "Yes" (Sim) a única escolha possível.

🚀 Sobre o Projeto
O objetivo deste projeto foi criar uma experiência digital memorável, utilizando elementos visuais como GIFs animados e efeitos de confete para celebrar uma resposta positiva. É uma demonstração prática de como a tecnologia pode ser usada para expressar sentimentos de forma criativa.

🛠️ Tecnologias Utilizadas
Para garantir a fluidez das animações e a interatividade, o projeto foi construído com:

HTML5: Estruturação dos cards de pergunta e sucesso.

CSS3: Responsável pelo fundo estilizado em tons de rosa, animações de confete e o posicionamento dinâmico dos botões.

JavaScript (Vanilla): Lógica principal que faz o botão "No" se mover aleatoriamente e gerencia a transição para a tela de "Congratulations!" após o clique em "Yes".

📱 Funcionalidades
Botão Fugitivo: Uma mecânica divertida onde o botão de negação se move ao ser focado ou clicado.

Feedback Visual Dinâmico: Uso de GIFs temáticos (como o personagem Patrick Star) para interagir com o usuário durante a pergunta.

Tela de Celebração: Após aceitar o convite, o usuário é recebido com uma mensagem de "Love You Baby!", chuva de confetes e um vídeo/GIF romântico comemorativo.

📈 Composição do Código

💡 Como utilizar
